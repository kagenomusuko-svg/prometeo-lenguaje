# promete-lenguaje

Isla lingüística de Prometeo. Registra propuestas asociadas a fragmentos y conserva modalidad, alternativas, proveniencia y contexto; no confirma ni calcula.

## Límite de autoridad

El lenguaje propone. promete-caso conserva las decisiones humanas. El texto recuperado de Paradigma se expone como contexto de sólo lectura y nunca como evidencia del caso.

## Desarrollo y verificación

Requiere Node.js 22 o superior. Ejecuta npm test. Las pruebas de integración interrepositorio requieren PROMETEO_CONTEXTO_PATH apuntando a promete-contexto/src/query.mjs.

Consulta INSTRUCCIONES.md para los pasos completos y CHANGELOG.md para cambios por versión.
